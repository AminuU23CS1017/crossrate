# Crossrate — hosted edition

Public Worker edition of the SP-050 currency tracker. The original FastAPI, SQLite/PostgreSQL implementation remains in the Crossrate GitHub repository.

The hosted adapter uses exact BigInt decimal multiplication, server-side Frankfurter requests and best-effort edge response caching (one-hour freshness; explicitly marked fallback up to seven days). Edge cache can be evicted; it is not a durable SQL database. Preferences, targets and conversion history remain browser-local. No background notifications or trading execution.

Run checks and rebuild:

```sh
node --test worker/api.test.mjs
node build.mjs
bash scripts/build.sh
node scripts/validate-artifact.mjs
```

Edit `worker/api.mjs` and `ui/`; `worker/index.js` is generated by `build.mjs`.
